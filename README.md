Entry for the make.fun bounty [news-image-20261117](https://make.fun/bounty/news-image-20261117?ref=5548afh3) — "Sum up 17 November's world news in one image".

One single editorial illustration for Tuesday 17 November 2026: the burning
tanker in the Strait of Hormuz, the missile strikes on Kyiv, the first
Xi–Trump–Putin meeting announced for Thursday in Shenzhen, the call to open
Gaza's aid crossings, and COP31 in Antalya — each scene labelled in plain
words, with the date across the top.

`main.py` (Python standard library only) copies the pre-rendered image
`entry.jpg` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).
